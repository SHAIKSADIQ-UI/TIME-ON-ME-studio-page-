# time-on-me-photography

Interactive 3D Photography Showcase Website featuring immersive Three.js camera interactions, GSAP animations, and modern web aesthetics.

## ✨ Features

- **Interactive 3D Camera Model**: Real-time 3D rendered camera using Three.js and GLTFLoader with smooth orbit and tilt controls.
- **Cinematic Animations**: Powered by GSAP for seamless section transitions and micro-interactions.
- **Photography Portfolio**: Visual galleries showcasing wedding, portrait, editorial, and commercial photography.
- **Modern Responsive Design**: Fully responsive layout tailored for high-DPI displays, tablets, and mobile devices.
- **Fast Build & Bundling**: Powered by Vite.

## 🛠️ Tech Stack

- **Three.js** - 3D scene rendering & GLTF model integration
- **GSAP (GreenSock)** - High-performance timeline animations
- **Vite** - Next-generation frontend tooling
- **HTML5 & CSS3** - Semantic structure and custom styling

## 🚀 Getting Started

### Prerequisites

- Node.js (version 18+ recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/SHAIKSADIQ-UI/time-on-me-photography.git
   cd time-on-me-photography
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
